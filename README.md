# Red Wine Quality Analysis and Prediction Using Machine Learning

## Project Overview

This project analyses the UCI Red Wine Quality Dataset using statistical analysis and machine learning techniques to understand physicochemical properties and predict wine quality.

The project explores regression, classification and unsupervised clustering approaches.

## Dataset

* Dataset: UCI Red Wine Quality Dataset
* Samples: 1,599
* Input Features: 11 physicochemical properties
* Target Variable: Wine Quality
* Source: UCI Machine Learning Repository

Dataset: https://archive.ics.uci.edu/dataset/186/wine+quality

## Project Objectives

1. Statistical analysis using correlation and ANOVA.
2. Wine quality prediction using regression models.
3. Classification using Logistic Regression and Decision Tree.
4. Clustering using K-Means.
5. Model evaluation, cross-validation and hyperparameter tuning.

## Machine Learning Algorithms

* Multiple Linear Regression
* Random Forest Regression
* Logistic Regression
* Decision Tree Classification
* K-Means Clustering
